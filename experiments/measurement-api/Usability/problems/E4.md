# 练习 4：给测量结果附加随机细标签

设 a、b 是有限量子系统的坐标指标集，I、J 是有限集。给定矩阵族 Kᵢ:a→b，满足 Kraus 归一化

\[
\sum_{i\in I}K_i^\dagger K_i=I_a.
\]

对每个 i，给定复振幅 cᵢⱼ，满足

\[
\sum_{j\in J}\overline{c_{ij}}c_{ij}=1.
\]

定义带细标签 (i,j) 的矩阵 Lᵢⱼ=cᵢⱼKᵢ。

1. 证明 L 是归一化 Kraus 族。
2. 分别构造效果为 Kᵢ†Kᵢ 与 Lᵢⱼ†Lᵢⱼ 的统计 POVM。对第二个 POVM 遗忘标签 j，证明所得 POVM 等于第一个。
3. 证明对每个复矩阵 A，两个非选择过程的输出相同：

\[
\sum_{i,j}L_{ij} A L_{ij}^\dagger
=\sum_i K_i A K_i^\dagger.
\]

并证明这两个归一化 Kraus 族所确定的 CPTP 信道相等。

要求结论对任意上述有限类型、矩阵和振幅成立。可按需使用常规有限类型、可判定相等和经典选择实例，不另加非空性假设。
