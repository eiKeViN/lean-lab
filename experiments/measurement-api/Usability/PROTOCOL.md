# Round 1：冻结协议

本轮四道自然语言题分别检验等价重标记、软二元判决、标签遗忘的 L1 区分度界、Kraus 细标签与过程保持。E2、E3 各有一名独立求解者仅使用原 Physlib/mathlib/既有 PMF 桥；对应另一名可用扩展库。E1、E4 各一名可用扩展库。所有求解者均不继承父对话，不共享解答，也不获知预期解法或指定引理。

准备版本的库为 f642cf3（基线 47d4740；增加两条一般效果上界），在题目与运行协议冻结前已编译、公理检查和真实消费者回归。题目从本提交开始冻结。源文件哈希、题目哈希和资源配置记录于 freeze.json。运行期间不得更改库；若需要修改，先保存首轮结果，后立新版本并标明同题迭代。

每题相同的 25 分钟任务预算，每个 Lean 进程限时 120 秒、单线程，允许正常源码检索和编译选项调整，但必须记录。绝对耗时受到并发、模型探索和环境影响；不把它当作受控性能基准。比较样本每路线一人，只能作小样本案例比较。

求解者仅得到自己的题目、LEARNER.md、所获资源路径、写入路径和记录器命令。父代理可以答复数学陈述或环境问题；任何帮助都要记录，且不得向其他求解者转述解答。事实记录与工具输出用于分析，不索取私有思考链。

边界为提示和目录约定，没有声称存在操作系统级文件隔离。共享环境中所有逻辑导入仍由 Lean 控制；原有路线不得导入扩展库。记录器检查显式导入并保存版本；最终审查再核对规格、编译、公理及是否使用了额外假设。

评价顺序：数学规格覆盖与假设；最终证明是否编译且仅标准公理；实际发现和适配成本；重复的数学/实现证明；帮助与未完成原因。行数和编译次数作为辅助数据。失败分为环境、API 可发现性/表达能力、表示与自动化适配、数学难点、测试约束；证据不足时保留未确定分类。
