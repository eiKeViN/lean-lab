# Fresh 36 million unit follow-up pair

One SHEAF (birch, CPUs 0–1) and one free run (larch, CPUs 2–3) start together from the first-round packet and empty project. No hints, code, DAG or transcripts are carried over. The 60-minute limit, maximum four live model sessions per arm, fixed gpt-6.1-sol/high with model fallback disabled, weighting and mathematical acceptance follow the parent protocol. The budget per arm is 36,000,000 units. There is only one new replicate per arm. This pair changes both budget and execution environment relative to round one.

At the first aggregate usage notification crossing 12M or 24M, save a live source snapshot and bracket it with the last available snapshot under that threshold. The terminal snapshot is taken after shutdown at 36M, or sooner if the run finishes. Report when a snapshot crosses the nominal budget and actual usage at stop. Grade A–E separately. The progression criterion for another pair is completion of B or C, or the first universal strip identity from D in either sector; another pair is a separate experiment. Partial proofs/lemmas and claims by the participants are reported separately.

Before launching, run four simultaneous fresh-room clients with known-good and deliberately invalid Lean statements importing the real QECert HGP module. Check that the invalid case returns the expected Lean diagnostic. Exercise the long-running job, polling, awk, and the rsync copy, exclusion, and deletion operations used by the pinned template. The four-room transport test shares two compile lanes. In the experiment each arm has its own lane, serializing top-level lean/lake calls in that room; it may schedule long jobs of up to 600 s without blocking its model. Long job status is visible to all roles in the same room.

For reproduction use the same runtime dependencies as round one, plus real Debian rsync and libpopt under runtime/round2-tools, and the host mawk and flock. The packages used were rsync_3.5.0+ds1-0+deb13u2_amd64.deb (SHA-256 ae4136280d73f307f0908d9aa8e0f05d94b9ad8c35124ba9b83cb994c2f337e8) and libpopt0_1.19+dfsg-2_amd64.deb (SHA-256 07f649b706852af937654295697dcfc7858f3295718ec18681dce1704663e4f2). Copy usr/bin/rsync and the resolved libpopt.so.0 to that directory. The room mounts them read-only.

From the runtime root use `python supervisor/experiments/hgp-erasure/supervision/launch_pair.py . pair36` after successful preflight. Evaluators discard participant build outputs, use the same frozen dependencies, and record proof type, allowed axioms and connection to the packet. The public report distinguishes verified deliverables from independently recovered prefixes and unverified work.
