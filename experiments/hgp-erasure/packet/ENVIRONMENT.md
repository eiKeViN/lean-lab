# Working environment
The working directory opened by the shell is /work. The seeded Lake project
is project/lean. Commands may use ordinary Linux programs, Lean 4.33.1, Lake,
and the frozen local source trees /opt/qecert and /opt/qecert/.lake/packages.
Use the local Lake manifest. The Lean 4 user guide and programming aids from
lean4-skills are available at /opt/lean4-skills. No external network is
available. The project files you create persist for your whole run, and
colleagues you launch share the same working tree. The host provides shell and
independent agent sessions, their status, messaging, and checkpoints. Each
session uses the same model and reasoning setting. The experiment controller
handles time, usage, and periodic snapshots. You may finish once your
deliverable is ready.
