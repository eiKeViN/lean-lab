# Source at the stopping point

These are the final mathematical source files and the target map where one
existed. They are preserved byte-for-byte, including build and proof errors.
`manifest.json` records hashes and original paths. The four root imports are
unchanged from the starter. For cedar and flint the new mathematical files
were still in worker sandboxes. Maple and slate wrote in the seeded project.
Compiler probes, scratch drafts and the minute-by-minute sources are in the
separate run evidence archive. Use the public packet for statement meanings.
