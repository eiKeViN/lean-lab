## 2. 固定目标与四条完成链

源码精确命题保持：

```lean
def ClassificationStatement : Prop :=
  ∀ (G : Type u) [Group G] [Finite G] [IsSimpleGroup G],
    ∃ i : CFSGIndex, Nonempty (G ≃* i.Group)
```

数学验收分别跟踪：

1. **穷尽性**：任意有限单群进入一个经证明的分类出口。
2. **出口识别**：出口标准模型与固定 `i.Group` 有实际 `MulEquiv`，并证明参数有效。
3. **名单正确性**：每个固定列表载体有限、非平凡且单；不能从穷尽命题推出这点。
4. **依赖闭合**：最终分类、名单正确性及所有桥接可重放，未引用最终 CFSG 作为中间依据。

Type 0 的结果可用已有 `classificationStatement_of_zero` 升至任意宇宙。`Nonempty` 是存在性结论，不额外要求实现可执行的任意有限群分类算法。

索引实际含 17 个 Lie 构造子、26 个散在名字及循环、交错两类。`Valid` 只规定参数和重复代表排除，本身不证明单性。Lie 候选按源码说明为 `D/Z(D)`，其中 `D = Fix(F)′`；必须取得底层 `FixedPointCandidate` 定义核对，不能换成 `Fix(F)/Z(Fix(F))`。固定载体和索引的 hash/声明指纹应由 E00 持续守护。

## 5. 归纳上下文与 K 群循环

建议数学规格：

```text
SmallSimple(G) := 对每个有限单群 S，|S| < |G| ⇒ Listed(S)
Listed(S)      := ∃ i : CFSGIndex, Nonempty (S ≃* i.Group)
```

这是待选择 Lean API 的规格，不是已编译代码。I00 证明：若 `H < G`，H 的任意简单 section S 满足 `|S| ≤ |H| < |G|`，SmallSimple 给出具体列表同构。文献的“真子群均 K”“真 section 均 K”等不同版本分别从强归纳推导，不混用名称。

- 不从“组成因子已知”直接推任意子群组成因子也已知；应以嵌于真 section 的阶界重新调用归纳。
- quasisimple 分量应对 `L/Z(L)` 等简单商分类，先证简单性和严格阶界；不能把 quasisimple 当 simple。
- `Aut(S)`、半直积、universal completion 可能比 G 大，不能因“在局部分析里”就调用当前阶归纳。
- 非阿贝尔单群中非单位 involution 中心化子为真子群，需要有证明；不能泛称所有中心化子都真。
- Z01 用阶强归纳供给 SmallSimple；Z00 消费它。I00 不得回头 import Z00；K00 族内结构不得 import 最终 CFSG。

每个归纳调用记录 `(ambient, section, simplicity proof, strict_card_bound)`。参考定理需要更强前提时新增接口卡并证归纳可供给，不能在适配时藏进 typeclass。

## 6. 覆盖性要交付可复核路由

旧路由可作初始工作分区：阿贝尔；非阿贝尔奇/偶；低 2 秩；高秩下 D；非 D 下 C2；C2 下低/高宽度。逻辑分区不等于已经接上文献分类。

须建立关联产物：

1. **路由定义表**：逐字定义 `m₂`、`D`、`C2`、`e₂`；证明有限最大值存在、同构不变和量词范围正确；明确 2-local、p-rank 的取值范围。
2. **覆盖矩阵**：每行含输入谓词、来源定理完整假设、桥接卡、例外、输出模型、载体桥、归纳调用、状态。允许覆盖重叠，不允许无去向残余。

D 是中心化子奇核商的非平凡 layer 原始谓词，不能自动等同某来源完整 component-type 假设；`¬D` 不自动推出 C2。`C2 ∧ e₂≤2` 不自动等于 strongly quasithin 或 QTKE。原始 e₂ 范围可能与文献宽度不同，必须证明桥接；失败则改中间分区或增例外。

## 7. 重型桥接的可执行拆分

### T07：非 D 且非 C2 的残余

文献编队先取得精确约化及其依赖，证明编队核对它确实处理：有限非阿贝尔单群、偶数阶、`m₂≥3`、`¬D`、`¬C2`、显式小 section/K 假设。不能预先断言这组条件必矛盾或只有有限多个孤立群；若来源产生无限参数族，出口表照实记录。

拆为 `T07.spec`（精确假设/输出）、`T07.local`（由 ¬C2 取见证 Q，分析 M=N_G(Q)）、`T07.reduce`（推出来源定理假设）、`T07.cases[j]`（剩余构形消除或识别）、`T07.exit[j]`（模型到固定列表）、`T07.cover`（case 穷尽）。spec 审阅通过不算定理通过；local 不能借用未证 reduce。候选约化不成立时，独立假设/反例编队提交具体差异，重选约化，继续独立基础工作。

### T03–T06：商分量到全群识别

拆成“商中的 layer/分量→适当原像与中心扩张→平衡/交换控制→标准分量或异常→族内局部识别→具体载体”。提升并非把商分量天然视为原群同名子群；须精确陈述核、中心、subnormal 性和扩张引理。

逐标准分量族记录 characteristic、rank、field、覆盖群/中心商、小参数区域。只按消费者拉取 involution centralizer 或外自同构作用等表项，不等待所有散在表。混合构形、弱闭性失败、非标准形进入有归属的异常队列。

### T09–T11：quasithin 与几何

T09 至少有：原始宽度→来源定义；所需 K/局部可解条件；第一部分局部结构；两部分间 QTKE 数据转换；最终识别；排除参数及例外；固定出口。各卡沿用同一定义签名，防止前半 quasithin、后半却要求更强 strongly quasithin。

T10 至少有：局部模→parabolic/amalgam 数据；连接性；单连通或适用替代条件；universal completion→G；满射与核控制；中心商；标准 Lie 模型；固定载体。仅构造 building 或 BN-pair 不等于全群同构。T11 是几何以外真实识别流，不得假定高宽度全部 Lie 型而删去散在例外。

## 8. 名单和固定载体前置

A/C/B₂/Suzuki 已有比较应优先复用：A/C 有 `carrierEquivPinned` 和保 Steinberg 声明；B₂ spin 有 `spinEquivPinned` 及 Steinberg 相容；Suzuki Candidate 有 `groupEquivFixedPoints`、`groupEquivSuzukiGroup`。总装注释“比较待完成”不能成为全部重做的理由，已有 ambient 比较也不等于所有族有限单性已证。

共用传输链：ambient 同构且与 F 交换→固定点同构→导群同构→中心商同构。须有足够群生成，不能只验简单正根公式就推全群相容。普通/图扭曲有限固定点、半 Frobenius 平方关系和有限系数域下降分别有有限性义务。

N00 六个排除代表须逐个给同构：A₁(4)、A₁(5)→A₅；A₁(9)→A₆；A₂(2)→A₁(7)；A₃(2)→A₈；B₂(3)→²A₃(2)。识别产出这些模型时经正规化，不能伪造被排除索引。另追踪 B/C 命名、低秩、小域导群例外；²F₄(2)′ 走 Tits 独立索引。图扭曲 q 是小域 Frobenius 参数，不能把 q²/q³ 系数域大小填作 q。

每个散在名字至少三流：独立模型及有限单性；局部识别到模型；固定呈示到模型的同构。满射 `P →* X` 只给下界，不能证明 P 有限；还需上界、核为零、规范形或逆映射。Fi₂₄′ 的 `fi24PrimeGroupMulEquivCommutator` 是实际可复用桥，但源呈示与真正 Fischer 群的联系仍需证明。Monster 的转录、关系长度和 Coxeter 改写同构不提供存在性/单性；79 关系的 M×2 与增加中央关系后 80 关系的 M 必须区分，并核验其完整数学论证。

Monster 应尽早审计可复用的模型、局部唯一性和中心扩张证明，缺失才重建。大内存/证书节点可向人类请求；默认全元素或最小置换作用枚举不能代替巨型群结构路线。

## 11. 数学验收禁区

- 逻辑 case split 不能记作文献分类覆盖。
- K-proper 条件分类不能记作无条件 CFSG。
- 名字、阶相等、角色表相同、呈示关系成立不能记作同构。
- 全名单有限单性不能视为穷尽命题的推论。
- Valid、源注释和 metadata 检查不能当作结构定理。
- 最终 CFSG 不能经 Schreier、Out、子群表包装倒灌主线。
- 编译图无环不能替代归纳阶下降和跨库回边审核。
- 路由规格、伪接口、假设化证明不能记作已验证完成。

建议主文采用复用优先、父义务到细卡映射、先行重桥契约和按族释放。完成标准是固定目标、全名单正确性、完整可重放依赖同时闭合。
