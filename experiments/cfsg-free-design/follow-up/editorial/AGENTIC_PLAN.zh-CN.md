# 通过智能体协作完成 CFSG 的 Lean 形式化

2026-11-11；状态：已交付团队材料的后续文档整合，供未来立项与实施评审。

本主文依据[用户补充要求](USER_FOLLOWUP.md)，忠实整合[数学路线稿](reviews/MATH_REVIEW.zh-CN.md)、[运行模型稿](reviews/OPERATING_MODEL.zh-CN.md)和[独立保证稿](reviews/ASSURANCE.zh-CN.md)。三稿是原始详细设计，技术细节以其对应章节为依据；本轮只整合文档，未实施 CFSG，未部署未来系统，也未对本主文另作团队独立复审。

接受完整 CFSG 的 Lean 形式化已经公开存在、任务已知可行为前提。实施采用**审计后复用优先、缺口自主重建**，由智能体承担检索、拆解、迁移、证明、证书、交叉审阅和集成，人类提供设施与稀缺专业支持。公开发布中“数十 agents、约24天”不揭示内部流程，也不验证本项目工期。以下所有未来槽数、设备、人数、日期、价格和吞吐均为待实测配置、试验阈值或现金情境，不是已获资源或完成保证。

## 1. 固定目标与资源前提

保持固定 TauCeti 的索引、参数有效性、具体载体和传递定义，目标为：

```lean
def ClassificationStatement : Prop :=
  ∀ (G : Type u) [Group G] [Finite G] [IsSimpleGroup G],
    ∃ i : CFSGIndex, Nonempty (G ≃* i.Group)
```

最终同时关闭四条链：任意有限单群的穷尽分类；每个识别出口到固定载体的实际乘法同构及参数正规化；全名单载体的有限、非平凡、单性；全部根声明和计算证书的可重放依赖。宇宙零证明须经已有 `classificationStatement_of_zero` 运输至任意宇宙。存在同构不额外要求实现任意有限群的可执行识别算法。

人类须为未来项目提供完整源码、工具链、文献、模型服务与计算权限。当前房间的会话数、工具或资料限制不作为未来资源上限。可行性不保证任意指定载体定义正确：若发现差异，提交精确反例或证明与修复选项，相关出口保持未完成，由目标所有者决定，其他分支继续。

## 2. 可审计复用与证据边界

[工作计划](design/agentic-workplan.json)保留固定 Mathlib/TauCeti 提交及全部50个父义务；每包依次考虑审计复用、接口适配、缺口新证。取得完整公开 CFSG 源码、工具链、blueprint、证书与许可后，可迁移任意粒度中间证明，包括奇数阶、signalizer 和 quasithin 重型模块，无须重复发现全部数学。

每个复用候选交付源提交与许可证、原目标完整类型差异、参数与例外、传递声明及数据依赖、公理报告、固定基线重放日志和真实消费者测试。最终 CFSG 及依赖它的 Schreier、外自同构或结构表不能回流作本项目分支前提；公理闭包干净仍须检查语义循环。失配模块隔离后提取独立子图、局部重证或换路线，其余可用模块继续。

其他 Lean 成果同样准入；Coq 等成果可复用数学分解，在 Lean 重证或通过另证健全的转换；文献必须核正文、假设、例外与勘误。GAP/Magma、AI和搜索可生成候选及证书，结论须经已证健全检查器进入内核证明。

三稿记录本地90份源码长度/hash吻合、17个Lie构造子和26个散在名字覆盖，但这些不证明 Lean 编译、参数全覆盖或数学正确。现有 `fixedToolchain: false`，完整参考实现及若干底层定义正文尚未取得；路径表和书目不等于定理或全文已读。未来首先补工具链锁、全导入闭包及合法全文，分别登记“来源线索、正文核对、已重放、消费者接入”。详见[数学稿第1–3节](reviews/MATH_REVIEW.zh-CN.md)。

## 3. 数学主线与全部分支

50个父包是义务追溯账本，实际执行按细定理卡的声明依赖。历史 `reference_depends_on` 不直接充当运行屏障：K00按“族×性质×参数区间”按需供给；A00–A02按通用运输和各族释放；N00逐个小同构交付。拆边须有实际依赖依据，不能删除数学困难。

| 工作流 | 首批可消费接口与最终去向 |
| --- | --- |
| E00/E01、F00–F04、I00 | 环境与证书工具、section阶界、互素作用、归纳上下文 |
| R00–R02、O00–O02 | 按消费者抽取角色论/模理论，完整奇数阶可解定理排除非阿贝尔奇数阶单群 |
| C00、A00–A02、L01–L05、N00 | 循环/交错出口、17个Lie构造子及全合法参数的载体桥和有限单性 |
| S00–S07 | 26个散在群逐群模型、局部识别、固定呈示双向桥；Monster早开深线 |
| T00–T06、K00 | 全部低2秩情形、signalizer、奇核商分量提升、标准分量及逐族识别 |
| T07 | 非D且非C2残余的约化、全部构形或参数族及固定出口 |

| Z00–Z02 | 消去局部归纳前提，完成全宇宙分类、名单正确性与闭包审计 |

先建 `SmallSimple(G)`：每个严格小于G阶的有限单群均有固定列表同构。I00证明真子群H的简单section S满足 `|S|≤|H|<|G|`；Z01以阶强归纳供给上下文，Z00消费它。每次调用记录环境群、section、单性证明和严格阶界；quasisimple分量对其简单中心商处理。不能免费假定K群对子群封闭，不能对可能更大的 `Aut(S)`、半直积或几何全成群调用当前阶归纳，I00不得反向导入最终分类。

初始分区为阿贝尔/非阿贝尔、奇/偶、低/高2秩、高秩下D/非D、非D下C2/非C2、C2下低/高宽度。D涉及中心化子奇核商的layer，C2涉及2局部正规化子的特征2条件，宽度涉及2-local中的奇素数秩；须冻结准确量词、最大值和同构不变性。逻辑分区不等于来源分类覆盖，`¬D`不能自动推出C2，低宽度不能直接当QTKE。

路线队维护覆盖矩阵：输入谓词、来源完整假设、桥接卡、例外、输出模型、载体同构、归纳调用、责任队和状态。T07拆为spec/local/reduce/cases/exit/cover，不预设只有有限孤立例外；T03–T06明确商分量原像、中心核、subnormal性和平衡；T09保持两卷间相同QTKE定义；T10证明连接性、所需单连通性、completion到G的核控制及模型同构，不能止于building或BN-pair。取得参考真实路线后可替换中间约化，但必须给旧义务到新证明的覆盖映射。详见[数学稿第4–7节](reviews/MATH_REVIEW.zh-CN.md)。

## 4. 名单、具体载体与计算证书

优先重放已有A/C/B₂/Suzuki比较。公共运输链是与F相容的ambient同构→固定点→导群→中心商；核对Lie载体确为 `D/Z(D)`、`D=Fix(F)′`，并补有限性、生成性和全参数证明。扭曲参数q不可换成系数域大小q²/q³；Tits群独立处理。

N00逐一证明 A₁(4)、A₁(5)→A₅，A₁(9)→A₆，A₂(2)→A₁(7)，A₃(2)→A₈，B₂(3)→²A₃(2)，识别出口经正规化构造合法索引，不能放宽 `Valid`。

散在群每个名字分三流：独立模型及有限单性、局部识别到模型、固定呈示到模型。满射只给模型阶的下界，仍需呈示阶上界、核消失、规范形或逆映射。Fi₂₄′已有改写桥须再接真正模型；Monster须区分79关系的M×2与增加中央关系后的80关系M，转录和Coxeter改写不证明有限单性。优先审计结构、局部唯一性和中心扩张路线，不默认巨型枚举。

证书绑定原始输入、解析、格式、检查器健全性、成功证明与结论桥；分块须证明各块及合并健全，记录峰值资源。工具准入用错生成元、删关系、截断及伪阶界做拒绝演练。详见[数学稿第8节](reviews/MATH_REVIEW.zh-CN.md)及[保证稿第3–6节](reviews/ASSURANCE.zh-CN.md)。

## 5. 64→256槽的组织与职责

槽表示同时执行任务的进程容量。先导为6个八席数学编队加16共享槽，共64；通过测量扩至128、256。常态24队共192数学槽：基础归纳3队，表示/奇数阶4队，Lie4队，散在4队，低秩/signalizer/分量4队，特征2/quasithin/几何4队，路由总装1队。

每队八席固定为规划1、文献复用1、实施3、接口1、对抗审阅1、集成1。三实施席可并行不同子引理或参数族，高风险才作有差异的竞争证明。共享64槽分配：调度依赖图8、检索12、编译性能12、证书工具8、独立审计16、记忆交接发布8；审计中4槽常驻路线、定义与异常覆盖。重型包另由跨队独立审阅，作者不独自终验。

编队可自主拆卡、检索、证明和预算内重排；核心接口由消费者与独立语义审阅共同守护，高影响语义变更交指定专家。改变最终目标、公理/信任边界、超预算或访问权限须由人类所有者决策。512槽只作实测收益充分后的选项。完整职责表见[运行稿第2节](reviews/OPERATING_MODEL.zh-CN.md)。

## 6. 定理卡、消费者与调度

卡记录ID/版本、父义务、完整类型及隐含实例/宇宙、来源定位、允许依赖、参数例外、归纳阶界、模型载体、负责人/审阅者/消费者、源码补丁、构建/公理/证书报告、预算与失败历史。

生命周期为 `proposed → specified → ready → leased → candidate → kernel_passed → independently_reviewed → consumer_integrated → released`。ready要求前置已可用、消费者合同和预算明确；规格、带洞候选和条件装配留在隔离区。内核通过后仍核对命题语义，消费者必须在真实目标中导入、提供全部假设并构造出口。父卡仅在全部必要子义务及装配通过后关闭，接口改版使受影响验收失效。

例如Lie识别消费者要求保持Steinberg映射的ambient同构，再接固定点、导群、中心商；遇剔除参数转N00。只交同阶或未相容同构拒收。净产能只计首次独立验收且消费者集成的卡，重复不计，撤销扣回，并按基础、运输、重建、重桥、证书分层，防止切碎短引理虚增进度。

调度同时维护研究图和发布证明图，按关键路径、解锁消费者数、复用价值及不确定性降低/代理时排序；人工等待、内存和失败史单列约束。每队在制实现卡初设不超过实施席两倍，同卡最多三种不同策略；就绪不足转拆卡和审计。两周滚动消费者需求、每日阻塞检查、周度资源重排。租约初设30分钟、5分钟心跳，原子认领与递增世代号阻止过期实例覆盖，事件幂等。协议见[运行稿第3–4节](reviews/OPERATING_MODEL.zh-CN.md)。

## 7. 并发隔离、可信构建与记忆

每次尝试用锁定提交的独立工作树，领域路径限权，上游只读，公共定义受保护，主干由发布机器人写入。PDF、注释和网页是资料，不能成为执行权限。接口变更交旧新类型、语义差异、消费者迁移补丁及回滚点；合并冲突由集成服务解决并重放消费者。

流水线依次检索完整声明、规格核对、最小目标、差异策略、局部编译、独立集成。编辑反馈、卡级集成、包/发布冷重放分队列；缓存键包含工具链、全部依赖、源码、选项、证书和检查器。记录排队、elaboration、kernel、内存与IO，按实际影响构建。

发布逐根核对实际完整类型、定义闭包、隐含参数和公理；基础白名单按锁定核心声明身份核验，拒绝 `sorryAx`、新增数学公理和隐藏分类假设。原生求值、外部回调及替换实现审查信任影响；优先内核可重放证书。两处独立管理环境从锁定源码与证书冷重建，不以开发缓存为唯一证据，封存命令、摘要、时长和峰值资源。

记忆分事实、数学知识、经验、决策四层，事实以提交和重放为准；检索按卡装配上下文。换会话必须交目标、环境、最后可编译提交、补丁、已证引理、失败最小重现、未证步骤、禁用路线、剩余预算和下一项区分性实验，接手先重放。三轮同错或单卡预算耗尽转接口诊断/拆卡/换来源；一周重路线无信息增益则比较备选并专家会诊。验收缺陷沿真实下游闭包撤销隔离，修复后重验，无关分支继续。详见[运行稿第5–8节](reviews/OPERATING_MODEL.zh-CN.md)。

## 8. 人类设施与专业支持

资源负责人按“数量、交付人、期限、服务等级、替代项、退出条件”落实资源单：完整固定仓库与工具链、参考实现和许可、图书馆全文/勘误/OCR复核、模型端点、Git/CI、事件数据库、检索索引、对象存储和恢复机制。GAP/Magma等用于候选与证书生成。

先导建议8台32核/128GB构建节点、20TB存储和分离冷重放机，另供沙箱及检索。256槽情境预留沙箱512 vCPU/2TB；构建池32台64核/256GiB，共2048核/8TiB，若其中4台换1TiB则总11TiB，报价按替换更新；另设4台证书专用节点、100TB可扩展存储及两处冷重放。模型吞吐配额单独采购，沙箱CPU不能当推理算力；自托管与API方案互斥核算。

人类先导8–12 FTE，常态情境20 FTE：数学8、Lean4、基础设施3、文献2、独立审计2、资源负责人1，可跨机构分时。专家聚焦定义、重型桥、例外、中心核、归纳循环和具体未解问题；普通lemma不逐条人工批准。专家意见产生来源记录或新证明卡，不能代替Lean证明。详见[运行稿第9节](reviews/OPERATING_MODEL.zh-CN.md)。

## 9. 启动、扩容与预算产能情境

90天是从材料与设施就绪起算的建议先导窗口：第1–7天锁环境并试两处重建；8–21天64槽打通循环群和具体载体消费者；22–45天做section归纳、A₁(7)/A₁(4)、M₁₁、奇数阶、分量及QTKE深样本，至少两项重模块闭包审计/适配试验，Monster单列关键片段；46–60天用分层匹配的独立任务池测16/32/64及候选128槽；61–90天过门槛才扩容并更新全任务图。样本未闭合也须交可复现缺口，不要求90天完成重型证明。

初始扩容阈值为消费者成功率≥80%、7日返工≤10%、加倍槽净吞吐≥1.5倍、单位集成成本增幅≤25%，且公理政策全合格、就绪充分、审阅和构建不饱和；这些仅为可调整管理阈值。先导抽60–100张预审卡，至少三分之一跨领域或重接口，冻结难度和命题，报告成本、返工、人工等待、CI尾延迟、剩余义务与关键路径，不以小群外推Monster。

类内净产能按“活跃代理时×审阅保留率×返工折减÷每次尝试时÷平均尝试数”估计，再受就绪、构建、专家和集成最小服务率限制。工期还受串行关键路径及发布重放下界约束，按实测分布滚动重估。

仅作可复算现金假设：输入/输出每百万token为5/25美元，每活跃槽日600万/80万token，得50美元；256槽、利用率0.65、30日模型费249,600美元/月。设施5–15万美元/月；20 FTE每人年全负担25–40万美元；加20%储备后约85.95–127.95万美元/月。同口径6/12/24个月约516–768、1031–1535、2063–3071万美元，均是费用乘法，未给完成概率或实测工期。模型费作0.25/1/4倍敏感性，实际按token账单、爬坡人数与设备占用积分，采购和迁移另列，避免重复计费。详见[运行稿第10–12节](reviews/OPERATING_MODEL.zh-CN.md)。

## 10. 全任务闭合与本轮交付

未来按M0环境/语义锁定、M1全复用/缺口图、M2真实垂直出口、M3全部实际重型依赖闭合、M4全路线及名单闭合、M5独立发布推进，可交叉并行。每个分支、参数区间、例外和出口必须有责任人及证明状态；不能用导入大定理、关闭多数子卡或条件分类提前通过。
